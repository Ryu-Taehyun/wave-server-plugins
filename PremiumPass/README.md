# PremiumPass - 야생 서버용 프리미엄 패스 플러그인

배틀패스(로얄 패스) 방식의 시즌 패스 플러그인입니다.

- **대상 서버**: Paper 1.21 이상 (Java 21)
- **설치**: `PremiumPass-1.0.0.jar` 를 `plugins/` 폴더에 넣고 서버를 재시작합니다.
- 처음 실행하면 `plugins/PremiumPass/` 폴더에 설정 파일들이 생성됩니다.

## 무료 트랙 / 프리미엄 트랙

레벨은 모두가 함께 올리고, 레벨마다 **무료 보상**과 **프리미엄 보상**이 따로 있습니다.

| | 무료 패스 | 프리미엄 패스 |
|---|---|---|
| 레벨 보상 | 무료 트랙만 (홀수 레벨, 5/10레벨 단위) | 무료 + 프리미엄 트랙 (모든 레벨) |
| 퀘스트 포인트 보상 | 기본 | **+50%** (`premium.quest-point-bonus`) |
| 교환 상점 | 일반 상품 | 일반 상품 + **프리미엄 전용 상품** (겉날개, 신호기) |
| 소급 수령 | - | 중간에 활성화해도 이미 지나간 레벨의 프리미엄 보상을 받을 수 있음 |

**프리미엄 패스 활성화 방법**
1. **프리미엄 패스권 아이템**: `/passadmin voucher <플레이어> [개수]`로 지급하고, 플레이어가 우클릭하면 활성화됩니다. 후원 상점이나 상자 보상에 그대로 넣어 쓸 수 있습니다.
2. **명령어**: `/passadmin premium <플레이어> <on|off>`. 콘솔에서도 실행되므로 후원 플러그인 연동에 쓸 수 있습니다.
3. **권한**: `premiumpass.premium` 권한이 있으면 프리미엄으로 취급합니다 (LuckPerms 등급 연동).

프리미엄 패스는 **시즌 단위**입니다. 새 시즌이 시작되면 해제되며, 유지하려면 `premium.keep-on-new-season: true`로 바꾸면 됩니다.

## 시스템 구조

```
퀘스트 완료 ─▶ 패스 XP ─▶ 레벨업 (1 ~ 100) ─▶ 레벨 보상 수령
     │                     │
     │                     └─ 100레벨 이후 XP ─▶ 프리미엄 패스 포인트로 전환 (100 XP = 1pt)
     └─ 보너스 포인트 ───────────────────────────▶ 프리미엄 패스 포인트 ─▶ 교환 상점
```

| 항목 | 기본값 |
|---|---|
| 레벨 상한 | 100 |
| 레벨당 필요 XP | 1,000 (`level.increase-per-level` 로 점점 늘어나게 설정 가능) |
| 100레벨 초과 XP | 100 XP 당 1 포인트 |
| 일일 퀘스트 | 17개 중 매일 5개 무작위 배정, 한국시간 0시에 초기화 |
| 시즌 퀘스트 | 16개 |

## 플레이어 명령어 (`/pass`, `/패스`)

| 명령어 | 설명 |
|---|---|
| `/pass` | 메인 메뉴 (GUI) |
| `/pass 보상` | 레벨 보상 화면: 위 줄이 무료, 아래 줄이 프리미엄 (클릭하면 수령) |
| `/pass 일일` / `/pass 시즌` | 퀘스트 진행 현황 |
| `/pass 상점` | 포인트 교환 상점 (상시 판매) |
| `/pass 모두수령` | 받을 수 있는 보상을 한 번에 수령 |
| `/pass 정보` | 레벨, XP, 포인트 확인 |

퀘스트 보상(XP, 포인트)은 퀘스트를 완료하는 즉시 자동으로 지급됩니다.

## 관리자 명령어 (`/passadmin`, `/패스관리`, 권한 `premiumpass.admin`)

| 명령어 | 설명 |
|---|---|
| `/passadmin reward <레벨> <free\|premium>` | **보상 편집 GUI**: 아이템을 넣고 창을 닫으면 저장됩니다 |
| `/passadmin reward <레벨> <free\|premium> addhand` | 손에 든 아이템을 해당 보상에 추가 |
| `/passadmin reward <레벨> <free\|premium> clear` / `view` | 보상 삭제 / 보상 확인 |
| `/passadmin premium <플레이어> <on\|off>` | 프리미엄 패스 활성화 / 해제 |
| `/passadmin voucher <플레이어> [개수]` | 프리미엄 패스권 아이템 지급 |
| `/passadmin shop add <id> <가격> [시즌제한] [premium]` | 손에 든 아이템을 교환 상점에 등록 (`premium`을 붙이면 프리미엄 전용) |
| `/passadmin shop premium <id> <true\|false>` | 프리미엄 전용 여부 변경 |
| `/passadmin shop remove <id>` | 상점 아이템 삭제 |
| `/passadmin shop price <id> <가격> [시즌제한]` | 가격, 구매 제한 변경 |
| `/passadmin shop list` | 상점 목록 |
| `/passadmin xp <플레이어> <양>` | 패스 XP 지급 |
| `/passadmin points <플레이어> <give\|take\|set> <양>` | 포인트 관리 |
| `/passadmin level <플레이어> <레벨>` | 레벨 설정 |
| `/passadmin info <플레이어>` | 플레이어 정보 |
| `/passadmin dailyreset <플레이어>` | 일일 퀘스트 다시 배정 |
| `/passadmin season next [이름]` | 다음 시즌 시작 (전원의 레벨, 보상 기록, 시즌 퀘스트, 구매 횟수 초기화) |
| `/passadmin reload` | 설정 파일 다시 불러오기 |

오프라인 플레이어에게도 XP, 포인트, 레벨 관련 명령어를 쓸 수 있습니다.

## 설정 파일

| 파일 | 내용 |
|---|---|
| `config.yml` | 시즌, 프리미엄 설정(보너스, 패스권 모양, 구매 안내 문구), 레벨 상한, 필요 XP, 포인트 전환 비율, 일일 퀘스트 |
| `quests.yml` | 일일 퀘스트 풀, 시즌 퀘스트 (종류, 대상, 수량, XP, 포인트) |
| `rewards.yml` | 레벨별 무료(`free`) / 프리미엄(`premium`) 보상. 게임 안 GUI로 편집하는 것을 권장합니다. 콘솔 명령어 보상(`commands`)도 지원합니다 |
| `shop.yml` | 교환 상점 (아이템, 가격, 시즌당 구매 제한) |
| `playerdata/*.yml` | 플레이어 데이터 |

### 퀘스트 종류

`BREAK_BLOCK`, `PLACE_BLOCK`, `KILL_MOB`, `FISH`, `CRAFT`, `SMELT`, `ENCHANT`, `BREED`, `CONSUME`, `PLAYTIME`, `COMPLETE_DAILY`

- `targets` 에는 `*` 와일드카드를 쓸 수 있습니다 (예: `"*_LOG"`). `HOSTILE` 은 모든 적대 몹을 뜻합니다.

### 악용 방지

- 직접 설치한 광석이나 원목을 다시 캐는 것은 퀘스트에 반영되지 않습니다.
- 농작물은 다 자란 것만 인정합니다.
- 스포너에서 나온 몹은 기본적으로 제외합니다 (`quests.count-spawner-mobs`).
- 크리에이티브 모드에서의 행동은 제외합니다.
- 접속 시간은 움직이고 있을 때만 인정합니다 (잠수 제외).

## 기본 보상 (임시, 야생 서버 기준)

### 무료 트랙
- **홀수 레벨**: 빵, 석탄, 횃불, 철 주괴, 화살 (레벨이 오를수록 수량 증가)
- **5레벨마다**: 경험치 병
- **10레벨마다**: 다이아 2~6개, 철 블록, 황금 사과, 내구성 책 등
- **100레벨**: 다이아 8, 불사의 토템 1, 황금 사과 4

### 프리미엄 트랙
- **1레벨**: 철 주괴 16, 황금 사과 2, 경험치 병 8
- **일반 레벨**: 철, 음식, 횃불, 원목 → 금, 청금석, 레드스톤, 경험치 병 → 다이아, 에메랄드, 철 블록 순으로 레벨이 오를수록 좋아집니다.
- **5레벨마다**: 다이아 + 황금 사과, 효율 책, 내구성 책
- **10레벨마다**: 다이아 5 / 셜커 상자 / 수선 책 / 불사의 토템 / 네더라이트 조각 / 행운 III 책 / 네더라이트 강화 형판 / 마법 황금 사과 / 신호기
- **100레벨**: 겉날개, 네더라이트 주괴 2, 불사의 토템 2, 마법 황금 사과 2

## 기본 교환 상점

경험치 병 32개 (20pt), 다이아 4개 (30pt), 셜커 상자 (120pt), 불사의 토템 (150pt), 수선 책 (250pt), 마법 황금 사과 (300pt, 시즌 5회), 네더라이트 강화 형판 (350pt), 신호기 (600pt, 시즌 1회, **프리미엄 전용**), 겉날개 (1000pt, 시즌 1회, **프리미엄 전용**) 등 19종.

## 다른 플러그인 연동

- 일일 상점(DailyShop) 버튼은 WaveCore 서버 메뉴(Shift+F)로 옮겨졌습니다. `/pass` 메인 메뉴: 레벨 보상 · 일일 퀘스트 · 시즌 퀘스트 · 교환 상점.
- 다른 플러그인은 `com.premiumpass.api.PremiumPassAPI`로 포인트 조회·차감·지급과 프리미엄 여부를 확인할 수 있습니다.

## 빌드

```bash
mvn install
```

빌드 결과물은 `target/PremiumPass-1.0.0.jar` 입니다. `install`을 쓰면 DailyShop 빌드에 필요한 PremiumPass가 로컬 저장소에 등록됩니다.

## 서버 전용 보상 (WaveCore 연동)
- 레벨 보상에 캐시, 상자 키(계정 지급), 천공의 제단 이동권 추가 (무료: 10·25·30·50·70·75·90·100, 프리미엄: 5레벨마다 캐시, 10레벨마다 키/이동권)
- 교환 상점에 10,000 캐시, 룰렛 키, 이동권, Echoes/Sealed/Ruiner 키 추가 (1포인트 ≒ 40 캐시 기준)
- 이미 rewards.yml / shop.yml 이 있는 서버는 새 파일로 교체해야 적용됩니다
- shop.yml 에 `commands:` 를 넣으면 아이템 대신 명령어로 지급 (item 은 표시용)

## 레벨 구매 / 패스권 판매 (WaveCore 연동)
- `/pass` 메뉴 24번 칸 "레벨 구매": WaveCore 의 `/패스레벨구매` 화면을 엽니다 (1레벨 1,750 유료 캐시, WaveCore config 에서 변경)
- 프리미엄 패스권은 WaveCore 유료 캐시 상점에서 판매 (25,000 유료 캐시)
- API: `PremiumPassAPI.getMaxLevel()`, `addLevels(player, n)`, `createVoucher(amount)`
