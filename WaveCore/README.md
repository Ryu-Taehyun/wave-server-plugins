# WaveCore - Wave Online Skript → Java 변환 플러그인

`plugins/Skript/scripts` 의 .sk 파일 25개 기능을 하나의 Paper 플러그인으로 옮긴 것입니다.

- **대상 서버**: Paper 1.21 이상 (Java 21)
- **같이 쓰는 플러그인** (원래 Skript 가 명령어로 호출하던 것들, 그대로 필요):
  LuckPerms(`lp`), TAB(`tab`), CrazyCrates(`cc`), BetterRTP(`rtp`), EssentialsX(`nick`, `/back`), Vault(칭호 표시), WorldGuard(`protect` 구역), Multiverse(월드 로딩)

## 설치 순서 (기존 데이터 옮기기 포함)

1. 서버를 끄고 `WaveCore-1.0.0.jar` 를 `plugins/` 에 넣습니다.
2. **Skript 는 지우지 말고**, `plugins/Skript/scripts/` 안의 .sk 파일 이름 앞에 `-` 를 붙여 꺼 둡니다. (예: `-shop.sk`) → 같은 기능이 두 번 동작하지 않게 하기 위함입니다.
3. 서버를 켜고 콘솔(또는 OP)에서 한 번 실행합니다.
   ```
   wave migrate
   ```
   돈, 유료 캐시, 레벨, 닉네임 색상/칭호/랭크, 우편함, 배낭, 팀/팀 창고, 장터, 밴 목록, Soul Splitter 킬 수, 저장 상자 등이 옮겨집니다.
4. 결과를 확인한 뒤 서버를 끄고 Skript 플러그인과 .sk 파일을 제거합니다.
   - `wave migrate` 를 두 번 실행하면 우편함·장터 등이 중복으로 추가되니 한 번만 실행하세요.
5. 필요하면 `/wave setwarp spawn`, `/wave setwarp protect` 로 `/spawn`, `/보호구역` 도착 위치를 지정합니다. (지정하지 않으면 각 월드 스폰)

## GUI 공통 규칙

- 맨 아래 줄: `◀ 이전 페이지`(왼쪽 끝) · `뒤로 가기`(가운데 왼쪽) · `닫기`(가운데) · `다음 페이지 ▶`(오른쪽 끝)
- 맨 위 가운데: 내 정보 (상점에서는 보유 캐시, 구매 즉시 갱신)
- 뒤로 가기 경로: 하위 상점 → 상점 → 메뉴 / 프로필 하위 → 프로필 → 메뉴 / 컬렉션 하위 → 컬렉션 → 메뉴 / 패키지 미리보기 → 유료 캐시 상점
- 우편함은 45칸씩 페이지로 나뉘고 `모두 수령` 버튼이 있습니다.
- 배낭과 팀 창고는 아이템을 넣는 칸이라 버튼 줄이 없습니다.

## 보스: 천공의 심판자

**맵 설치 (천공의 제단, `sky_altar.schem`, 65×42×65)**
1. `sky_altar.schem` 을 `plugins/WorldEdit/schematics/` (FAWE 는 `plugins/FastAsyncWorldEdit/schematics/`) 에 넣습니다.
2. 제단을 놓을 하늘 위치(예: y 150 이상, 주변이 비어 있는 곳)에 서서 `//schem load sky_altar` → `//paste` 합니다.
   제단 **중앙 윗면이 서 있던 위치**에 오도록 기준점이 맞춰져 있습니다.
3. 붙여넣은 제단 **중앙에 서서** `/wave boss setcenter` 를 입력합니다. 이 위치에서만 보스가 스폰됩니다.
4. 플레이어가 올 수 있도록 워프(Essentials `/setwarp` 등)를 만들어 두세요.

**보스**
- 제단 48칸 안에 플레이어가 있으면 등장, 처치 후 30분 뒤 재등장 (`boss.respawn-minutes`)
- 금 갑옷을 입은 거대한 위더 스켈레톤, 체력 400, 보스바 표시, 제단 반경 22칸을 벗어나면 중심으로 귀환
- 패턴: **심판의 빛**(6초마다 1명 발밑에 1.5초 예고 후 번개 8), **천공의 파동**(14초마다 6칸 넉백 4), 체력 50% 이하 시 저항·신속 강화

**천공의 제단 이동권 / 메뉴**
- 서버 메뉴(Shift+F / `/메뉴`) 두 번째 줄: 프로필 · 레벨 · 컬렉션 · 프리미엄 패스 · **일일 상점** · **천공의 제단**(강림 중이면 빛남, 상태 표시) · 팀
- `[☀] 천공의 제단 이동권` (종이, **1회용**): 우클릭하면 **천공의 제단 메뉴**가 열림 (`/천공의제단`, `/제단이동`, `/천공` 도 메뉴만 열림)
- 메뉴(4줄, 맨 아래 줄은 닫기 버튼만): 보스 상태(강림 중 체력/남은 시간/참가자 · 다음 강림까지), **이동 버튼**, 전리품 & 규칙. 매초 갱신
- 전리품 & 규칙 클릭 → **전리품 목록** 창: 맨 위 희귀 전리품(클레이모어), 아래에 나올 수 있는 아이템과 수량. 확률은 표시하지 않음 (뒤로 가기 → 천공의 제단)
- 이동은 **메뉴의 이동 버튼 클릭으로만** 가능하고, 이동할 때 이동권 1개 소모 (관리자도 소모)
- 거부: 이동권 없음 / 심판자가 강림하지 않음 / 분배 중 / 이미 제단 안 / 전투 태그 중. 거부되면 이동권은 소모되지 않음
- 보스는 `respawn-minutes` 마다 플레이어가 없어도 강림 (강림 알림 클릭 시 메뉴 열림)
- 도착 지점: 기본은 제단 남쪽 입구, `/wave boss setentry` 로 변경
- 지급: `/wave boss ticket <플레이어> [개수]`, 전리품 풀에 `special: altar_ticket` 으로 넣을 수도 있음

**전투 제한과 귀환**
- 천공 월드(`boss.lock-world`, 기본 `sky`)에서는 **채팅을 제외한 모든 명령어가 항상 차단** (관리자 제외, `/루팅` 과 `boss.allowed-commands` 는 허용). 월드 전체가 제단 구역으로 취급되어 귀환/이동 제한 대상
- 전투가 끝난 뒤 천공 월드에서 접속하면 자동으로 이전 위치(없으면 스폰)로 이동
- 천공의 제단에서 사망하면 이전 위치(없으면 스폰)에서 부활하고, 이번 강림에는 다시 입장할 수 없음 (다음 강림부터 가능). 사망하면 보스에게 준 피해와 관계없이 전리품 분배에서 제외되고, 분배 도중 사망하면 그 사람의 주사위는 무효 처리
- 천공 월드에서는 항상(관리자 제외): Shift+F 메뉴 · 메뉴 버튼 · 겉날개(활공 즉시 해제) · 엔더 진주 · 후렴과 · 월드 밖으로 나가는 모든 텔레포트 차단. 나가는 방법은 귀환(처치 후/시간 초과)과 사망뿐
- 보스 전투 제한 시간 5분 (`boss.fight-minutes`). 보스바에 남은 시간 표시 (제단에 플레이어가 아무도 없으면 시간이 멈춤, "대기 중" 표시), 지나면 보스가 사라지고 제단 안 플레이어는 이전 위치로 이동
- 처치 후 1분 (`boss.return-seconds`) 이 지나면 자동으로 이전 위치로 이동. 주사위를 전부 다 돌렸으면 10초 (`boss.return-after-roll-seconds`) 뒤 이동
- 이전 위치 = 제단(중심에서 `boss.arena-radius` 48칸)에 들어오기 직전 위치. 걸어서 들어왔으면 스폰
- 전투 중 ~ 귀환 전까지 제단 안에서는 명령어(/루팅 제외, `boss.allowed-commands` 로 추가 허용)와 제단 밖으로 나가는 텔레포트(명령어, 플러그인, 엔더 진주, 후렴과)가 막힘. 관리자(wave.admin)는 예외

**전리품과 주사위 분배**
- 처치할 때마다(혼자여도) 보스에게 피해를 준 참가자 전원에게 3줄(27칸) 창이 열리고, **전리품 5개**가 무작위 칸에 나옵니다.
- 아이템마다 따로: **좌클릭** = 주사위(0~100), **우클릭** = 포기. 참가자 전원이 고르면 그 아이템은 가장 높은 숫자에게 (동점은 먼저 굴린 사람). 혼자면 좌클릭 즉시 획득.
- 클레이모어 획득 시 전체 알림(위아래 구분선)과 획득자 화면에 타이틀(타이틀: Arbiter of Heaven, 서브타이틀: 아이템 이름)
- 분배가 끝날 때까지 전리품 창은 닫아도 다시 열림
- 30초가 지나면 남은 아이템도 결정: 굴린 사람이 있으면 최고 숫자에게, 아무도 안 굴렸으면 제단에 떨어짐.
- 천공의 심판자 클레이모어는 `boss.loot.claymore-chance`(기본 0.5%) 확률로 5개 중 하나로 섞여 나오고, 나오면 참가자에게 알림이 뜹니다.
- 전리품 목록·개수·비중은 `boss.loot.pool` 에서 수정 (material 또는 special: quantum_matter, vibranium, time_shard, mending_book)
- 당첨자가 오프라인이면 우편함, 창을 닫았으면 채팅 메시지 클릭 또는 `/루팅`

| 관리자 명령어 | 설명 |
|---|---|
| `/wave boss setcenter` | 서 있는 위치를 제단 중심(보스 스폰)으로 지정 |
| `/wave boss spawn` | 즉시 소환 |
| `/wave boss kill` | 보스 제거 (보상 없음) |
| `/wave boss info` | 상태, 재등장까지 남은 시간 |
| `/wave boss setentry` | 서 있는 위치를 이동권 도착 지점으로 |
| `/wave boss ticket <플레이어> [개수]` | 천공의 제단 이동권 지급 |
| `/wave boss testloot [claymore]` | 전리품 창 테스트 (아이템이 실제로 생성됨, claymore 를 붙이면 클레이모어 포함) |

## 설정 (`config.yml`)

월드 이름, 대전 시작 좌표, 최대 체력, 전투 태그 시간, 보호구역 이름, IP 고정 목록, 신고 받는 관리자, 링크, 스폰 경험치 구역을 바꿀 수 있습니다.

**최대 체력**: `health.base` 가 기본 체력, `health.claymore-bonus` / `health.frost-bonus` 가 각 무기 소지 시 추가 체력입니다. 두 무기를 모두 가지면 더 큰 값 하나만 적용됩니다.

| 무기 상점 | 엔더 진주 2000 보유 확인 후 1000 차감·16개 지급, 숨은 토템 구매 | GUI 표시대로 1000 → 8개, 토템(4000) 표시 |
| 레벨 16 보상 | 비어 있음 | Soul Splitter (GUI 표시와 동일) |
| Soul Splitter 킬 수 | 커스텀 모델 데이터가 있는 **모든 아이템**의 설명을 덮어씀 | Soul Splitter 만 |
| 도박 | 3초 대기 중 돈을 쓰면 음수 잔액 | 결과 시점에 다시 확인 |
| 대전 | 대전 중 접속 종료 시 영원히 대전 상태 | 상대 승리로 종료 |
| 점검 모드 | 켠 관리자도 재접속 시 추방 | `wave.maintenance.bypass`(OP) 는 접속 가능 |
| 컬렉션 공지 | 변수가 없던 기존 유저는 공지 안 됨 | 처음 획득 시 공지 |
| `/속도` | 1초 뒤 체력/속도 갱신에 덮어씌워짐 | 무기 소지 상태가 바뀔 때만 갱신 |

**권한 추가**: `/openinv`(다른 사람 인벤토리 보기), `/givecrown`(아이템 지급), `/testkill`(전체 공지)은 원본에 권한이 없었는데 관리자 전용으로 바꿨습니다. 일반 유저도 써야 한다면 알려주세요.

## 옮기지 않은 것

- `{protected_zone.location}`: 원본에서도 텔레포트 직후 `/mv tp` 로 덮어써져 실제로 쓰이지 않았습니다. 대신 `/wave setwarp` 를 쓰세요.
- `{whisper.last}`: 저장만 하고 사용하는 명령어(/답장)가 없었습니다.
- 상점.sk 의 "Sealed Master Power" 구매 처리: 이 창을 여는 명령어가 어느 파일에도 없습니다.
- `/추첨`: 원본처럼 "우편함으로 보상이 지급되었습니다" 공지만 하고 실제 보상은 없습니다.

## 킬 알림 / 킬 특수 효과

- 크라운 표식 + 클레이모어/프로스트 그레이브 처치: 해당 무기 알림 형식 그대로, 좌표만 금빛

- 오른쪽(15)은 결과 미리보기와 새로 얻는 능력, 아래 줄은 필요한 아이템별 ✔/✘ 와 보유/필요 수량
- 올린 칼날을 클릭하거나 창을 닫으면(접속 종료, 서버 종료 포함) 인벤토리로 돌려받음
- 필요 아이템은 이전과 같음

## Umbral Chain (`[✦] Umbral Chain`, 보조 무기, 무기 상점 55,000 캐시)
- Time piecer Wind 와 같은 포지션의 보조 무기: 같은 이름/설명 양식, 등급 Epic, 쇠사슬 아이템 (서버 버전에 맞춰 IRON_CHAIN / CHAIN)

- 수치는 config `weapons.shade` (chance, pull-strength, bind-seconds, slow-level, cooldown-ms)

## Echo Bell (`[✦] Echo Bell`, 보조 무기, 무기 상점 50,000 캐시)
