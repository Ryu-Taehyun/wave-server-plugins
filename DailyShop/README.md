# DailyShop - 일일 상점 플러그인

매일 상품이 바뀌는 일일 상점입니다. 단독으로 쓸 수 있고, PremiumPass와 함께 쓰면 패스 포인트 결제와 프리미엄 할인이 연동됩니다.

- **대상 서버**: Paper 1.21 이상 (Java 21)
- **설치**: `DailyShop-1.0.0.jar`를 `plugins/` 폴더에 넣고 서버를 재시작합니다.

## 동작 방식

- 매일 초기화 시각(기본 한국 시간 0시)에 `shop.yml` 목록에서 상품 **6개**를 무작위로 골라 진열합니다.
- 모든 플레이어에게 같은 상품이 진열되고, 구매 한도는 **플레이어별로 하루 단위**입니다.
- **가중치**가 클수록 자주 진열됩니다. 8 이상은 일반, 3~7은 희귀, 1~2는 영웅으로 표시됩니다.
- 서버를 재시작해도 그날의 진열과 구매 기록은 유지됩니다.

## 결제 수단 (`config.yml`의 `currency.type`)

| 값 | 결제 | 필요한 플러그인 |
|---|---|---|
| `PREMIUMPASS` (기본) | 프리미엄 패스 포인트 | PremiumPass |
| `VAULT` | 서버 돈 | Vault + EssentialsX 등 경제 플러그인 |
| `ITEM` | 아이템 (`currency.item`, 기본 에메랄드) | 없음 |

설정한 결제 수단을 쓸 수 없으면 서버 로그에 경고를 남기고 아이템(에메랄드) 결제로 대신 동작합니다.
`VAULT`로 바꾼다면 기본 가격이 포인트 기준이라 낮으니 `shop.yml`의 `cost`를 서버 경제에 맞게 올려 주세요.

## PremiumPass 연동 (함께 설치했을 때)

- 프리미엄 패스 보유자는 **10% 할인**을 받습니다 (`premium-discount`).
- `premium-only: true` 상품은 프리미엄 패스 보유자만 살 수 있습니다.
- 상점 화면에 "프리미엄 패스 열기" 버튼이 생깁니다. (일일 상점 버튼은 WaveCore 서버 메뉴(Shift+F)에 있습니다.)

## 명령어

| 명령어 | 설명 |
|---|---|
| `/일일상점` (`/dailyshop`) | 일일 상점 열기 |
| `/dailyshop admin add <id> <가격> [하루한도] [가중치] [premium]` | 손에 든 아이템을 상품으로 등록 |
| `/dailyshop admin remove <id>` | 상품 삭제 |
| `/dailyshop admin list` | 상품 목록과 오늘 진열 |
| `/dailyshop admin reroll` | 오늘 진열 다시 뽑기 (구매 기록 초기화) |
| `/dailyshop admin reload` | 설정 다시 불러오기 |

권한: `dailyshop.use` (기본 전원), `dailyshop.admin` (기본 OP)

## 설정 파일

| 파일 | 내용 |
|---|---|
| `config.yml` | 진열 개수, 초기화 시각, 결제 수단, 프리미엄 할인율 |
| `shop.yml` | 상품 목록 (가격, 하루 한도, 가중치, 프리미엄 전용) |
| `state.yml` | 오늘 진열과 구매 기록 (자동 관리) |

## 기본 상품 20종 (임시, 야생 서버 기준)

- 일반: 철 블록 8 (20), 금 블록 4 (15), 다이아 2 (12), 경험치 병 16 (8), 황금 사과 2, 황금 당근 32, 엔더 진주 8, 폭죽 로켓 32, 흑요석 16, 슬라임볼 16, 에메랄드 16
- 희귀: 블레이즈 막대 8, 이름표 2, 효율 V 책 (80), 보호 IV 책 (80), 셜커 껍데기 2 (60)
- 영웅: 불사의 토템 (100), 수선 책 (180), 네더라이트 조각 (150), 마법이 부여된 황금 사과 (250, 프리미엄 전용)

## 빌드

PremiumPass 연동 코드를 컴파일하려면 먼저 PremiumPass 폴더에서 `mvn install`을 실행한 뒤:

```bash
mvn package
```

## WaveCore 캐시로 구매
- WaveCore 가 있으면 일일 상점 상품을 **캐시(일반)** 로도 살 수 있습니다.
- 좌클릭 = 포인트로 구매, 우클릭 = 캐시로 구매
- 캐시 가격 = 포인트 가격(할인 적용 후) × `cash.per-point` (기본 40)
- config:
```yaml
cash:
  enabled: true
  per-point: 40
  display-name: "캐시"
```
